# CIO移动应用概要

## 项目概述

CIO移动应用是一款面向中国国内用户的智能信息助手，基于先进的大模型技术和工具代理系统，提供专业的情报收集、分析和决策支持。本应用旨在成为用户的"首席情报官"，帮助用户在信息爆炸的时代高效获取、筛选和理解关键信息。

## 核心功能

1. **智能查询交互**
   - 自然语言对话界面
   - 多轮深度交互能力
   - 推理过程可视化
   - 支持上下文理解与延续

2. **信息源管理**
   - 多种信息源接入（网页、RSS、API等）
   - 自定义刷新频率
   - 信息源分类与标签
   - 信息质量评估

3. **关注点跟踪**
   - 设置重点关注领域
   - 自动收集相关信息
   - 关注点信息汇总
   - 定期分析与更新

4. **情报分析**
   - 信息提取与整合
   - 观点与趋势识别
   - 多源信息对比
   - 可靠性评估

5. **个人助理功能**
   - 信息推送与提醒
   - 个性化推荐
   - 使用习惯适应
   - 用户偏好学习

## 技术实现

### 前端技术栈

- **框架**: React Native + TypeScript
- **UI组件**: React Native Paper
- **状态管理**: Redux + Redux Toolkit
- **API请求**: React Query
- **导航**: React Navigation
- **离线支持**: Watermelon DB (计划中)

### 目录结构

```
src/
├── api/           # API服务层
├── components/    # 可复用组件
├── config/        # 配置信息
├── hooks/         # 自定义Hooks
├── navigation/    # 导航配置
├── screens/       # 页面组件
├── store/         # Redux状态管理
├── types/         # TypeScript类型定义
└── utils/         # 工具函数
```
