# CIO (Chief Intelligence Officer)

## 项目概述

CIO是一款面向C端用户的个人情报助手应用，将自动化信息采集与智能交互相结合，帮助用户建立个人信息生态系统。作为"每个用户的首席情报官"，CIO旨在从信息过载中解放用户，提供精准、个性化的信息服务。

本项目是在[Wiseflow](https://github.com/TeamWiseFlow/wiseflow)和[OpenManus](https://github.com/mannaandpoem/OpenManus)的启发下创建的，结合了两者的优势：Wiseflow的自动化信息采集与OpenManus的智能交互能力。

## 核心功能

- **智能信息采集**：自动从多种信源获取与用户关注点相关的信息
- **情报分析与整理**：智能过滤、分类和摘要采集到的信息
- **交互式情报查询**：通过对话方式与系统交互，查询特定信息
- **个人知识库**：自动构建和管理用户的个人信息资料库

## 技术架构

- **前端**：移动端应用（Flutter/React Native）
- **后端**：基于Python的信息处理引擎
- **数据存储**：轻量级数据库
- **AI能力**：集成大语言模型处理和分析信息

## 开发阶段

当前项目处于第一阶段开发中，专注于构建最小可行产品(MVP)，实现基础的信息采集和交互能力。
